## Publishing rules

- Assign one preferred page to each query; do not create multiple near-identical pages.
- Link news articles back to the relevant evergreen hub and link hubs to their strongest supporting articles.
- Create TP1–TP6 pages only when each page has distinct, sourced planning information—not templated keyword substitutions.
- Every time-sensitive claim needs a date and source. Every investment page needs explicit risk and independent-verification guidance.
- Use descriptive slugs for new articles. Preserve existing numeric article URLs unless a tested redirect migration is planned.
